## 💡 Sobre mim

Gosto de transformar processos manuais em sistemas bem feitos: automações, dashboards, portais e integrações. Meu foco é entregar aplicações completas — modelagem de dados, API e front-end — com atenção a detalhes que fazem diferença no dia a dia de quem usa.

- 🏗️ Aplicações web modernas com **TypeScript**, **React** e **Next.js**
- 🐍 Automação de dados e pipelines com **Python**
- 🗄️ Modelagem e otimização de bancos **PostgreSQL** (Supabase, Neon)
- 🤖 Explorando **IA aplicada ao desenvolvimento** com a API da Anthropic
