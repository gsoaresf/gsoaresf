## Projetos

Meu trabalho atual é uma suíte de sistemas internos para uma gestora de
investimentos, em repositórios privados:

- **Portal do investidor:** área logada para os clientes da casa
- **ERP interno:** sistema de gestão das rotinas operacionais
- **Intranet:** centralização de processos e ferramentas do time
- **Integrações:** conectores entre os sistemas internos e provedores de dados de mercado
- **Site institucional:** presença pública da gestora
- **Agentes de IA:** skills e automações aplicadas à análise de crédito
